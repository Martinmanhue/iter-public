# Colaborar con la vista previa pública de Iter

Este repositorio no acepta contribuciones al código principal de Iter porque ese código permanece privado.

Sí puedes colaborar mediante comentarios sobre:

- claridad de la propuesta;
- sintaxis de la vista previa;
- formatos y bibliotecas prioritarios;
- casos de uso reales;
- errores de documentación;
- accesibilidad y presentación;
- límites que deberían explicarse mejor.

## Antes de abrir un issue

Comprueba que no exista una conversación equivalente. Después incluye:

1. el problema que quieres resolver;
2. la herramienta, biblioteca, formato o backend involucrado;
3. cómo se realiza actualmente;
4. qué parte resulta repetitiva o confusa;
5. una propuesta breve de experiencia, cuando sea útil.

## Reglas

No publiques:

- credenciales o tokens;
- datos personales;
- código privado;
- contenido copiado sin permiso;
- información interna de Iter Server o Iter Storage;
- afirmaciones falsas sobre funciones disponibles.

## Código de ejemplo

Los ejemplos deben centrarse en la intención del usuario y dejar claro cuándo muestran sintaxis prevista en lugar de una función ya publicada.

Ejemplo:

```iter
iter convert data.json to data.csv
```

## Propiedad y licencia

Enviar una idea, comentario o corrección de documentación no concede derechos sobre Iter ni sobre sus productos relacionados. Consulta [`LICENSE`](LICENSE).
