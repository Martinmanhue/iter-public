# Política de seguridad

## Alcance de este repositorio

`iter-public` contiene únicamente documentación, recursos visuales y una vista previa técnica. No contiene el código principal de Iter, Iter Server, Iter Storage ni credenciales de producción.

## Informes de seguridad

No publiques vulnerabilidades sin corregir, credenciales, tokens, datos personales ni detalles sensibles en un issue público.

Un informe útil debería incluir:

- archivo o documento afectado;
- comportamiento observado;
- impacto posible;
- pasos mínimos para reproducirlo;
- corrección o mitigación sugerida, cuando exista.

## Información que nunca debe publicarse

- contraseñas o tokens;
- claves privadas;
- direcciones o datos personales innecesarios;
- rutas locales privadas;
- registros de producción;
- detalles internos de servidores;
- configuraciones de Iter Storage;
- código privado obtenido sin autorización.

## Investigación autorizada

No está permitido intentar acceder al repositorio privado, servicios, cuentas, datos o infraestructura de Iter sin autorización expresa.

Tampoco está permitido:

- interrumpir servicios;
- realizar escaneos agresivos;
- mantener acceso persistente;
- modificar o eliminar información;
- publicar detalles sensibles antes de una corrección coordinada.

## Estado del producto

Iter continúa en fase Release Candidate. No debe utilizarse en sistemas críticos hasta que exista una distribución oficial, documentación completa y una evaluación apropiada.
