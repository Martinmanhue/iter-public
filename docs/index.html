Iter busca ofrecer una experiencia común para trabajar con recursos, formatos, bibliotecas y backends. El usuario expresa la intención; Iter coordina la ejecución.

⭐ Ver en GitHub Ver la demostración

# una intención
# una instrucción

El problema no es aprender. Es reaprender lo mismo.

Operaciones parecidas suelen tener nombres, estructuras y configuraciones diferentes. Iter busca conservar la intención común sin ocultar diferencias importantes.

1

Expresa la intención

Convierte, crea, analiza, busca o guarda mediante instrucciones claras.

2

Iter resuelve

Identifica el recurso, los formatos y los adaptadores compatibles.

3

El adaptador ejecuta

La operación se realiza sin convertir toda herramienta en una caja negra.

Una experiencia centrada en la intención

Los ejemplos muestran el diseño previsto para el lanzamiento. La sintaxis puede ajustarse durante la validación.

Hoy

  • Imports y configuración.
  • APIs diferentes.
  • Resolución manual de formatos.
  • Código de integración repetido.

Con Iter

  • La intención aparece primero.
  • Resolución coordinada.
  • Adaptadores reutilizables.
  • Control manual solo cuando hace falta.
