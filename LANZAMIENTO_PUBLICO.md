# Lanzamiento público de Iter

Este documento organiza la comunicación inicial de la vista previa pública de Iter.

## Objetivo

Conseguir que una persona entienda en pocos segundos:

1. qué problema intenta resolver Iter;
2. cómo se expresa una intención;
3. cuál es el estado real del proyecto;
4. cómo seguirlo y participar.

## Mensaje principal

> **Aprende una vez. Usa cualquier biblioteca.**

Iter busca ofrecer una experiencia común para trabajar con recursos, formatos, bibliotecas y backends.

## Llamada principal

⭐ Marca **Star** para seguir el desarrollo y el futuro lanzamiento de Iter.

## Secuencia inicial de publicaciones

### Publicación 1 — Presentación

**Iter ya tiene una vista previa pública.**

Abrir datos, convertir formatos o cambiar de herramienta suele obligar a aprender interfaces distintas y repetir integraciones.

Iter explora una idea diferente:

> Aprende una vez. Usa cualquier biblioteca.

Repositorio público:
https://github.com/Martinmanhue/iter-public

### Publicación 2 — Demostración

Una intención, una instrucción:

```iter
iter convert data.json to data.csv
```

Iter busca conservar lo que el usuario quiere lograr y coordinar después los formatos, adaptadores y backends compatibles.

Vista previa pública:
https://github.com/Martinmanhue/iter-public

### Publicación 3 — Comparación

**Hoy:** una interfaz distinta por herramienta, integraciones repetidas y formatos resueltos manualmente.

**Con la visión de Iter:** una forma común de expresar intenciones y adaptadores reutilizables.

La vista previa pública explica la arquitectura y el estado actual:
https://github.com/Martinmanhue/iter-public

### Publicación 4 — Pregunta a la comunidad

¿Qué debería unificar Iter primero?

- Conversión de formatos
- Datos y tablas
- Recursos web

- Otra prioridad

Comparte tu caso de uso en el repositorio:

### Publicación 5 — Progreso verificable

Iter continúa en validación privada.

La comunicación pública solo anunciará como disponibles las funciones implementadas y probadas. El repositorio público contiene la visión, la arquitectura, ejemplos y la hoja de ruta.

⭐ Sigue el progreso:
https://github.com/Martinmanhue/iter-public

## Principios de comunicación

- Mostrar ejemplos concretos antes de usar afirmaciones grandes.
- Distinguir siempre entre visión, prototipo, validación y función disponible.
- No afirmar que Iter reemplaza Python o integra todas las bibliotecas.
- No publicar código privado, credenciales, tokens, datos personales ni componentes internos.
- Mantener una sola llamada por publicación: ver el repositorio, responder o marcar Star.
