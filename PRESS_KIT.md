# Kit de presentación de Iter

## Descripción breve

**Iter** es una vista previa pública de una propuesta para trabajar con recursos, formatos, bibliotecas y backends desde una experiencia común.

Su idea central es:

> **Aprende una vez. Usa cualquier biblioteca.**

## Qué problema intenta resolver

En muchos flujos de desarrollo, abrir datos, convertir formatos o cambiar de biblioteca significa aprender APIs distintas, repetir integraciones y reescribir partes del proceso.

Iter busca expresar la intención del usuario con una interfaz más uniforme.

## Ejemplo breve

```iter
iter convert data.json to data.csv
```

## Mensajes clave

- Una interfaz común para múltiples operaciones.
- La intención del usuario se expresa primero.
- Adaptadores y backends se resuelven después.
- La vista previa pública muestra la dirección del proyecto, no el producto final completo.
